# Beauty Salon Development

- Требования: [docs/SPEC.md](docs/SPEC.md). КТ-3 пройдена, блокирующих UX-проблем нет; некритичные замечания приняты. Дизайн сейчас не меняем. Демонстрационная публикация согласовывается отдельно.
- Astro 7, статическая сборка, TypeScript strict, обычный CSS. Node.js ≥22.23.4, рекомендован 24 LTS. Без React, CMS и серверной логики.
- `src/data/catalog.json` — единый источник услуг и цен; `catalog.ts` — Zod и проверки. `salon.ts` — контакты и тексты, `promotions.json` — предложения с `priceRef`. `source-pages.json` — исходный архив, не использовать для вывода цен. Источники и расхождения: `docs/content-inventory.md`.
- Layout: `src/layouts`; компоненты: `src/components`; страницы: `src/pages`; CSS и токены: `src/styles/global.css`; фото: `src/assets`.
- Услуги со статусами `conflict`, `paused`, `needs-confirmation`, а также дочерние услуги приостановленного направления нельзя показывать как доступные без подтверждения. Спорные цены и акции исключены и из полной версии. Для вывода использовать `publicCatalog`, а не исходный `catalog`.
- Обучение и сертификаты исключены. Запись сейчас только по телефону через `CallLink.astro`; YCLIENTS отдельно согласовывается.
- Реальные интерьер, команда и работы — только материалы салона. Не приписывать салону стоковые/AI-фото, рейтинги и неподтверждённые преимущества. Дизайн спокойный и читаемый, без люксового позиционирования.
- Команды: `npm ci`, `npm run dev`, `npm run check`, `npm run build`, `npm run check:site`, `npm run preview`. `check:site` запускать после build. Build формирует `dist/`; проверяет данные каталога. Временные проверки/скриншоты — `output/` (игнорируется Git).
- GitHub Pages: `.github/workflows/deploy.yml`, npm и Node.js 24. `SITE_URL` и `BASE_PATH` поступают из `configure-pages`; локально без них сайт работает от `/`. При проверке подпапки передавать одинаковый `BASE_PATH` в build, `check:site` и preview. Внутренние пути формировать через `siteHref` (`src/utils/urls.ts`), направления — через `directionHref`.
- Сайт и демонстрация остаются `noindex`; снятие запрета отдельно согласовывается для основного домена. Домен, canonical, sitemap, security headers и редиректы — этап окончательной публикации. В контактах разрешён официальный iframe Яндекс Карт; проверенная карточка и URL — в `salon.ts`. Сохранять независимую ссылку, lazy loading, зарезервированную высоту и защиту прокрутки от перехвата картой. Maps API и другие интеграции не добавлять без согласования. Не выполнять push, деплой и изменения действующего сайта без разрешения.
